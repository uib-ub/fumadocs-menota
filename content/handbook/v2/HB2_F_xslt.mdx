# F. Extensible Stylesheet Language Transformation (XSLT) [#secF]

Version 2.0 (16 May 2008). Links updated 12 July 2016.

## F.1 Introduction [#secF.1]

XSLT is a language for transforming XML documents into other XML documents, or other formats, e.g. HTML.

This page contains XSL Transformations (which we shall refer to as XSLT stylesheets) to be used with Menotic XML files 
		   in order to generate user-friendly HTML. To help users modify these stylesheets, they contain a number of comments 
		   explaining the intended effects of the stylesheet.

The XSLT stylesheets on this page have been developed by Vemund Olstad and Tone Merete Bruvik, Aksis, University of Bergen.

## F.2 XSLT for Menotic texts [#secF.2]

There are two XSLT stylesheets available:


		   

 - [menota-web-comment-P5.xsl](menota-web-comment-P5.xsl), 9 January 2008, for texts encoded according to _Menota 2.0_ (TEI P5 conformant)
 - [menota-web-comment.xsl](menota-web-comment.xsl), 25 May 2005, for texts encoded according to _Menota 1.1_ (TEI P4 conformant)

To download these stylesheets rather than opening them, right-click (on Windows) or ctrl-click (on Mac), 
		   depending on the preferences in your browser. Otherwise, you will most likely get an error report when your 
		   browser tries to open the XSL file.

These XSLT stylesheets will convert a text encoded with <E>facs</E>, <E>dipl</E> and/or <E>norm</E> tags into easily 
		   readable HTML display. Note that your computer must have a [MUFI compliant font](http://www.mufi.info) 
		   in order to display all characters correctly, especially on the <E>facs</E> level.

**2**. By defining one XSLT stylesheet for each level. In that case, you should switch 
		   comments in this pair of lines found at the beginning of the XSL file:
```xml
<!--<xsl:param name="visning" select="'norm'"/>-->
<xsl:param name="visning"/>
```


**2.1**. For <E>facs</E> display, make a stylesheet with this pair of lines:
```xml
<xsl:param name="visning" select="'facs'"/>
<!-- <xsl:param name="visning"/> -->
```


**2.2**. For <E>dipl</E> display, make a stylesheet with this pair of lines:
```xml
<xsl:param name="visning" select="'dipl'"/>
<!-- <xsl:param name="visning"/> -->
```


**2.3**. For <E>norm</E> display, make a stylesheet with this pair of lines:
```xml
<xsl:param name="visning" select="'norm'"/>
<!-- <xsl:param name="visning"/> -->
```


After having defined (and named accordingly) the XSLT stylesheets, you may generate HTML output in e.g. 
		   Oxygen as specified in (1) above. This time, you should not specify any parameter, since this has been 
		   done in the stylesheet itself (and for this reason you should define as many stylesheets as there are parameters).
