# Index of elements and attributes

Version 3.0 (12 December 2019),<br/>

		  	with minor changes to the <E>add</E>, <E>c</E>, <E>milestone/</E>, <E>pc</E> and <E>s</E> elements (30 December 2025)

Compiled and edited by Nina Stensaker



## 1. Introduction [#sec1]

This is an index of all elements and their attributes discussed in the handbook. For each element, we give a brief
				  definition and a link to the chapter where it is discussed and exemplified.

Most elements can have several attributes, and each attribute a number of values. We list the recommended 
				  attributes in the handbook, and we suggest which attributes are obligatory
					(Obl) and which are optional (Opt). We suggest values for each attribute, but unless otherwise stated 
					these lists are open-ended.

HTML elements such as <E>a</E>, <E>br</E> and <E>i</E> are discussed in a few
			    cases in the handbook (particularly in [ch. 2](/handbook/v3/ch2)), but are not included in the index. The same goes for possible (but discarded)
			    elements, such as <E>damageSpan</E>, <E>sicSpan</E>, <E>suppliedSpan</E>, 
			    <E>suppressedSpan</E> and <E>unclearSpan</E> (discussed in [ch. 16.2](/handbook/v3/ch16#sec16.2)). They are not part of the TEI repertoire nor 
			    recommended by Menota.
