# Ch. 13. Metrical structure

Version 3.0 (12 December 2019)

by Jon Gunnar Jørgensen, Jonna Louis-Jensen and Tarrin Wills

## 13.1 Encoding of metrical structures [#sec13.1]

It is recommended that passages of verse in manuscripts should be 
   encoded as such. The basic encoding of verse is covered in [ch. 3.8](/handbook/v3/HB3_ch3#sec3.8)
   above, where it is recommended that verse be encoded in line groups (i.e. stanzas) and lines.

The following section extends the basic mark-up of verse to include: (1) references to the relevant stanza 
within the whole poetic corpus, so that poetry can be cross-referenced between manuscript versions; and (2) markup
of metrical features within verses and lines.

There are good reasons to establish
a system for the encoding of metrics in the medieval manuscripts even
if this structure is not generally represented graphically in the
manuscripts. For many users of the established text the stanzas are
of great interest and it is therefore practical to mark them in a way
that makes it possible to find and delimit them from the surrounding
text. A more detailed encoding of the stanzas can open up for new
ways of research on different metrical variants, concerning e.g.
alliteration, internal rhyme and stress.

The same rules that apply for prose
are relevant also for the encoding of stanzas. In addition to these
rules we suggest codes that facilitate the search for and
identification of stanzas. We also give guidelines as to the encoding
of the metrics. It should be pointed out, however, that these codes
would have to be given a more detailed form if the stanzas should be
analysed in a more detailed way.

The verse will normally be marked up only at the `<me:dipl>{:xml}` and `<me:norm>{:xml}` levels of the transcription. 
For the `<me:facs>{:xml}` level, verse will be included as if prose, in accordance with the practice of the 
medieval manuscripts.

## 13.2 Elements and attributes [#sec13.2]

On the primary level we recommend
that the stanzas are encoded with the following elements and
attributes:

<div className="table-xml-elements">
| Elements & attributes | Obl/Opt | Explanation |
|-----|-----|-----|
| `<lg>{:xml}` |  | Marks the stanza in relation to the surrounding prose text.  |
| <span className="p-3"/>`@n{:sh}` | Obl | Indicates the identity of the stanza within the manuscript, i.e. its number in the manuscript, using values such as `"1"{:js}`, `"2"{:js}`, `"3"{:js}`.  |
| <span className="p-3"/>`@xml:id{:sh}` | Optional | Indicates the identity of the stanza within the medieval poetic corpus. The id should refer to a standard edition of the works. Menota recommends using the sigla for verses used by the Skaldic Poetry project ([https://skaldic.abdn.ac.uk/db.php](https://skaldic.abdn.ac.uk/db.php)) for non-Eddic verse, and the numbering in [Neckel and Kuhn 1983](/handbook/v3/HB3_literature#Kuhn1983) for Eddic verse. If no standard corpus contains the verse (e.g. rímur), it should be indicated by a separate typology.  |
| <span className="p-3"/>`@type{:sh}` | Optional | Indicates the general metrical form of the stanza, e.g. `"dróttkvætt"{:js}` or `"fornyrðislag."{:js}` |
| `<l>{:xml}` |  | Marks the line within the stanza. |
| <span className="p-3"/>`@n{:sh}` | Obl | Indicates the line number within the stanza, using values such as `"1"{:js}`, `"2"{:js}`, `"3"{:js}`. Lines are broken according to Norse-Icelandic conventions, that is, alliterative lines are treated as two lines, with a break at the caesura. |
| <span className="p-3"/>`@type{:sh}` | Optional | Indicates the type of line for formatting purposes; the implied value, `"normal"{:js}`, is not indented; use `"b-line"{:js}` for the b-line of eddic metres which should have the caesura represented by a long space; use `"ljod-long"{:js}` for <em>ljóðaháttr</em> long lines, which should have a line break and be indented. |
| <span className="p-3"/>`@met{:sh}` | Optional | Indicates the metrical form of the line. The form should be according to a standard typology, e.g. types A&ndash;E of the common germanic verse form. Sub-types can also be represented, using, e.g. [Gade 1995](/handbook/v3/HB3_literature#Gade1995). Alternatively, the actual scansion of the line can be represented using a series of symbols (e.g. ‘/’ for a lift, ‘\’ for a secondary stress, ‘x’ for a dip and ‘\|’ for a syntactic caesura; or cf. the [MUFI character recommendation](/handbook/v3/HB3_literature#MUFIrec) for metrical symbols).  |
| `<me:all>{:xml}` |  | Indicates the alliteration of the line.  |
| `<me:ass>{:xml}` |  | Indicates the internal rhymes of the line, where relevant.  |
</div>


## 13.3 Encoding example [#sec13.3]

The following example is from _Guta saga_ (ed. by [Peel 1999](/handbook/v3/HB3_literature#Peel1999), p. 2), in which the correction of the word “reð” has been suppressed for the sake of simplicity:

<div className="table-plain">
<table>
<tbody>
<tr>
<td>
<Quote>
 Hann reþ draum þinna so:<br/><br/> Alt ir baugum bundit<br/> Boland al þitta varþa<br/> ok faum þria syni aiga 
</Quote></td>
</tr>
</tbody>
</table>

</div>


The basic encoding of a verse within a prose work is thus:
```xml
<p>
  <w>Hann</w>
  <w>reþ</w>
  <w>dra<lb ed="ms" n="16"/>um</w>
  <w>þinna</w>
  <w>so</w>
  <pc>.</pc>
</p>
<lg n="1" xml:id="Guta-v1" type="germ">
  <l n="1">
    <w>Alt</w>
    <w>ír</w>
    <w>baugum</w>
    <w>bundit</w>
    <lb ed="ms" n="17"/>
  </l>
  <l n="2">
    <w>bo land</w>
    <w>al</w>
    <w>þitta</w>
    <w>warþa</w>
  </l>
  <l n="3">
    <w>oc</w>
    <w>faum</w>
    <pb ed="ms" n="1v"/>
    <w>þria</w>
    <w>syni</w>
    <w>aiga</w>
  </l>
</lg>

```


The verse is numbered as the first in the manuscript, and the value of `@xml:id{:sh}` is according to its own typology (this verse 
does not occur in most poetic corpora). The value of `@type{:sh}` simply represents that this is in the common Germanic metre. No
attempt has been made here to do more detailed metrical analysis.

The following example is of a more complex, skaldic example from _Skáldskaparmál_ in AM 748 II 4to. The verse (from Bragi Boddason’s _Ragnarsdrápa_ (stanza 5) is thus:

```xml
    <w><me:dipl>m<me:ass>yl</me:ass>um</me:dipl></w>
  </l>
  <l n="8" met="X">
    <w><me:dipl><me:all>h</me:all><ex>er</ex>gautz</me:dipl></w> 
    <w><me:dipl>vín<lb ed="ms" n="21"/>um</me:dipl></w>
    <w><me:dipl>bardir</me:dipl></w><pc>.</pc>
  </l>
</lg>
```


The value of `@n{:sh}` is 3, as this is the third verse recorded in the manuscript. The verse’s `@xml:id{:sh}` is the siglum from the  
   [Skaldic project](https://skaldic.abdn.ac.uk/db.php?table=verses&id=1939). The type of metre is `"dróttkvætt"{:js}`, 
but this categorisation is unnecessary, as the link to the skaldic project also provides information on the metrical category of each verse. 
Each line is encoded with the `<l>{:xml}` element, with the line number given and the metrical categorisation (here, from
   [Gade 1995](/handbook/v3/HB3_literature#Gade1995); “X” means 
uncategorised).

The alliterative staves are indicated using the `<me:all>{:xml}` element, and the internal rhymes using `<me:ass>{:xml}`. Both elements are defined by Menota and belong to the Menota namespace (cf. [ch. 2.8](/handbook/v3/HB3_ch2#sec2.8) above).
