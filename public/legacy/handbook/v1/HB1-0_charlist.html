Character list

Version 1.0 (20 May 2003)

 

This list includes all characters which we believe are needed in the transcription and display of Medieval Nordic texts. It is divided into two main sections.

1. Characters needed for the transcription (and hence display) of Medieval Nordic sources. These characters are those actually found in the primary sources themselves.

2. Characters that are not found in the primary sources, but are needed for the display of transcribed text. These characters are used to show unclear readings, metrical analysis and text critical information (on matters suchs as editorial additions, deletions and emendations).

The bulk of characters are base line characters, either simple (such as "a") or composite (such as "á"). A large number of composite characters are included in the Unicode standard, but new composite characters are not likely to be accepted. Unicode recommends that these characters are encoded and displayed as a combination of a base line character and a combining diacritical mark. This applies to e.g. "o ogonek with acute accent" (a glyph for this character is located here). By analogy, this principle also applies to composite characters which in fact are included in the Unicode standard, such as "á". For this reason, alternative encodings are given for a large number of characters in this list. These alternatives are strictly equivalent, and they are identical to the ones found in the Unicode standard.

For example, the character "á" can be encoded with the entity "&aacute;" and displayed with reference to the Unicode character 00E1 in the code chart Latin-1 Supplement. Alternatively, it can be encoded as a sequence of "a" and the entity "&combacute;", referring to the Unicode characters 0061 in Basic Latin and 0301 in Combining Diacritical Marks. In both cases, the correct glyph, "á", will be displayed.

Characters outside Basic Latin (US ASCII) are described as entities according to the rules set out in ch. 5 and 6.

The present list contains Unicode codepoints for all characters defined in Unicode 3.2. Characters outside the present Unicode standard have been allocated code points in the Private Use Area. The code points and descriptive name of these characters are shown in bold type (and dark blue).

For further discussion on Unicode and the Private Use Area, cf. the Medieval Unicode Font Initiative.

2. Characters needed for display only

2.1 Unclear characters (return to top)

We recommend that characters that are difficult to read are encoded with the <unclear> element. In text display such characters are usually shown with a dot below. Since in principle all characters can be difficult to read, the number of possible combinations is very high. It is therefore recommended that the combining dot below is used in display. Note, however, that no less than 38 composite characters with dot below is included in the range Latin Extended Additional.
